# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do not open a public GitHub issue. Instead, report it privately to the maintainers.

**Preferred:** use [GitHub private vulnerability reporting](https://github.com/andrewtryder/telegram-finance-bot/security/advisories/new).

You may also email: `1811535+andrewtryder@users.noreply.github.com`.

We will acknowledge receipt of your vulnerability report and work to resolve the issue promptly.

### Scope of Security Policy

This security policy covers:
- Core codebase under `bot/` directory.
- Secret leaks, packaging, and dependency concerns.
